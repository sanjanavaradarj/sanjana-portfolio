6-Month Capstone · 2023

Driver Drowsiness Alert System

Arduino Uno · Embedded C · Sensor Integration

Project Overview

This embedded systems project tackles one of the leading causes of road accidents — driver fatigue. An Arduino Uno microcontroller is interfaced with analog and digital sensors to continuously monitor driver alertness. When sensor readings cross predefined drowsiness thresholds, the system immediately activates an audible alarm to wake the driver and prevent accidents.

Key Features & Highlights

  • Arduino Uno microcontroller programmed in Embedded C for real-time processing
  • Multi-sensor input processing: eye blink / head tilt detection via analog sensors
  • Threshold-based alerting: configurable sensitivity for different driver profiles
  • Sub-second response latency — from sensor trigger to alarm activation
  • Low power design suitable for continuous in-vehicle operation
  • Potential integration path with vehicle power systems and buzzer hardware

Technologies Used
